# 우리 반 오목 대전

## 실행하기
1. [Node.js](https://nodejs.org) 설치 (LTS 버전)
2. `start.bat` 더블클릭 (처음 한 번은 자동으로 설치가 진행됨)
3. 창에 표시된 **학생 접속 주소**(예: `http://192.168.0.10:3000`)를 칠판/화면에 띄워 주기
4. 교사는 `http://localhost:3000/teacher.html` 접속 → 비밀번호 `1234`

- 학생 기기와 교사 PC가 **같은 와이파이/네트워크**에 있어야 합니다.
- 처음 실행할 때 Windows 방화벽 창이 뜨면 **허용**을 눌러 주세요.
- 비밀번호 변경: `set TEACHER_PIN=원하는번호` 후 `node server.js`
- 기록은 서버 메모리에 저장되므로, 서버를 끄기 전에 교사 화면에서 CSV로 내려받아 두세요.

## 기능
| 화면 | 내용 |
|---|---|
| 학생 | 이름으로 입장 → 자동 랜덤 매칭, 대회 중에는 대진에 따라 자동 배정, 순위표/대진표 보기, 기권 |
| 교사 | 실시간 경기 전체 관전, 학생별 상태·전적, 매칭 켜기/끄기, 한 수 제한 시간, 경기 판정(승/무/무효), 학생 내보내기, 기록 다시보기, CSV 내려받기 |
| 대회 | 리그전(조 편성 가능, 승 3·무 1·패 0점) / 토너먼트(부전승 자동, 무승부면 재경기) |
| 게임 방법 | 기본 규칙 · 한 판 따라보기(해설 시뮬레이션) · 이기는 모양 · 문제 풀기 · 컴퓨터와 연습 |

## 규칙
15×15 판, 흑 선공, 5개 이상 연속이면 승리, 금수 없음. 경기 중 연결이 끊기고 1분 안에 돌아오지 않으면 기권 처리됩니다.
