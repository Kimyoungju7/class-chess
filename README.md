# 우리 반 체스 대전

## 실행하기
1. [Node.js](https://nodejs.org) 설치 (LTS 버전)
2. `start.bat` 더블클릭 (처음 한 번은 자동으로 설치가 진행됨)
3. 창에 표시된 **학생 접속 주소**(예: `http://192.168.0.10:3000`)를 칠판/화면에 띄워 주기
4. 교사는 `http://localhost:3000/teacher.html` 접속 → 비밀번호 `1234`

- 학생 기기와 교사 PC가 **같은 와이파이/네트워크**에 있어야 합니다.
- 처음 실행할 때 Windows 방화벽 창이 뜨면 **허용**을 눌러 주세요.
- 비밀번호 변경: `set TEACHER_PIN=원하는번호` 후 `node server.js`
- 기록은 서버 메모리에 저장되므로, 서버를 끄기 전에 교사 화면에서 CSV로 내려받아 두세요.

## 인터넷에 무료 배포하기 (Render)
1. [render.com](https://render.com)에 GitHub 계정으로 가입
2. **New → Blueprint** → 이 저장소 선택 (`render.yaml` 설정이 자동 적용됨)
3. `TEACHER_PIN`(교사 비밀번호)을 물어보면 원하는 값 입력 → 배포
4. 몇 분 뒤 생기는 주소(예: `https://class-chess.onrender.com`)로 접속. 교사 화면은 주소 뒤에 `/teacher.html`

- 교사 화면 상단의 "학생 접속 주소"에 공개 주소가 자동으로 표시됩니다. 다른 곳에 배포할 때는 `PUBLIC_URL` 환경변수로 주소를 지정하세요.
- 무료 요금제는 **15분 동안 접속이 없으면 잠들고**, 깨어나는 데 1분쯤 걸립니다. 수업 몇 분 전에 주소를 한 번 열어 두세요.
- 서버가 잠들거나 다시 배포되면 **기록이 사라집니다.** 수업이 끝나면 CSV로 내려받으세요.
- 주소만 알면 누구나 들어올 수 있으니 비밀번호는 꼭 바꾸고, 주소는 수업 중에만 알려 주세요.

## 기능
| 화면 | 내용 |
|---|---|
| 학생 | 이름으로 입장 → 자동 랜덤 매칭, 대회 중에는 대진에 따라 자동 배정, 순위표/대진표 보기, 기권 |
| 교사 | 실시간 경기 전체 관전, 학생별 상태·전적, 매칭 켜기/끄기, 한 수 제한 시간, 경기 판정(승/무/무효), 학생 내보내기, 기록 다시보기, CSV 내려받기 |
| 대회 | 리그전(조 편성 가능, 승 3·무 1·패 0점) / 토너먼트(부전승 자동, 무승부면 재경기) |
| 게임 방법 | 기본 규칙 · 말의 움직임 · 체크/체크메이트/스테일메이트 · 특별한 규칙(캐슬링, 프로모션, 앙파상) · 컴퓨터와 연습 게임(기록 안 남음) |

## 규칙
8×8 표준 체스, 백 선공. 규칙 판정은 서버에서 [chess.js](https://github.com/jhlywa/chess.js)로 합니다. 체크메이트면 승리, 스테일메이트·기물 부족·3회 반복·50수 규칙이면 무승부. 프로모션 때는 퀸·룩·비숍·나이트 중에서 고릅니다. 경기 중 연결이 끊기고 1분 안에 돌아오지 않으면 기권 처리됩니다.
